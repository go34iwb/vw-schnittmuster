# VW T6 Innenverkleidung Projekt

## Zweck
Erstellung einer Schablone (Schnittmuster) für die Innenverkleidung eines VW T6 Fahrzeugs aus 4mm Pappelsperrholz.

## Kurzbeschreibung
Das Projekt enthält die HTML-Vorlage `schnittmuster-3.html`, die als Grundlage für die Fertigung der Innenverkleidung dient. Ziel ist es, die Vorlage zu prüfen, anzupassen und für die CNC-/Laserfertigung vorzubereiten.

## Wichtigste Funktionen
- Bereitstellung der Schnittmuster-Datei im HTML-Format
- Möglichkeit, die Maße und Formen anzupassen
- Dokumentation des Arbeitsfortschritts

## Verwendete Technologien
- HTML (Vorlage)
- Optional: CSS/JS für interaktive Vorschau (falls benötigt)

## Voraussetzungen
- Texteditor zur Bearbeitung von HTML
- éventuell ein Browser zur Vorschau
- Zugang zu Fertigungs equipment (Laser/CNC) für das Sperrholz

## Installation / Nutzung
1. Die Datei `schnittmuster-3.html` im Projekt-Öffnen.
2. Im Browser öffnen zur Sichtkontrolle.
3. Bei Bedarf im Editor anpassen (Maße, Schnittlinien usw.).
4. Angepasste Datei für die Fertigung exportieren.

## Tests
